# First

A C++ Unreal Engine 5 portfolio project. The repository root is the Unreal
project root, so a clone is directly openable: install Git LFS
(`git lfs install`), clone the repo, then double-click `First.uproject` - or open
it from the Epic Games Launcher. Because `EngineAssociation` is a machine-local
GUID, Unreal will ask which engine version to associate on a new machine; pick
your installed UE5 and let it re-associate, then let it generate project files
and compile the `First` module before the editor opens. Binary assets are stored
in Git LFS, so a clone without LFS installed will fetch pointer files instead of
real assets. Packaged builds and the demo video are not in this repo - they live
on Google Drive.
